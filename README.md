Interactive intial study and revision activities for Edexcel A-Level French (9FR0), built as self-contained web pages.
Built for Bolingbroke Academy Sixth Form, French and Spanish. Set works: La Haine (Kassovitz) and L’Étranger (Camus), Edexcel 9FR0.

Live site → https://artmemry.github.io/A-Level-French-BBA/

74 activities covering Themes 1–4, the two Paper 2 set works (La Haine and L’Étranger), and the grammar, vocabulary and translation skills that decide AO3 marks. Everything runs in the browser: no login, no server, no accounts, no data leaving the student’s device.

Open the site, put your name in the box at the top, and work through whatever your teacher has set.

Progress — tick Fait ✓ on each activity you finish and tap how it felt (😕 / 🙂 / 😃). This is stored on that device only, in that browser. Using a different computer means starting the checklist again.
Your code — the hub generates a short code beginning DOSFR1. that encodes your name and your ticked activities, nothing else. Send it to your teacher through the Microsoft Forms button, or copy and paste it. It is a snapshot you choose to send, not live monitoring.
Backups — Sauvegarder exports dossier-francais-progression.json; Restaurer reads it back. Use this if you change computer.
Downloads — most activities produce a .txt (or PDF) of your answers once you have entered your name. Drop that file into Teams or SharePoint as your evidence of work.
