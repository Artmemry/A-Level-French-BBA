# A-Level French — upload set

113 files, all destined for the **root** of `artmemry/A-Level-French-BBA`.
Drag the whole contents of this folder in. GitHub's web uploader takes at most
100 files per commit, so it goes in two drops — or press `.` on the repository
to open github.dev and drag once.

## Two things the upload cannot do for you

**Delete `SP1_famille_maitrise_du_contenu.html`.** It is a stale, older copy of
a page the hub already lists as `FR1_famille_maitrise_du_contenu.html`. An
upload adds and replaces; it never removes. Delete it on GitHub afterwards.

**Delete `SP1_famille_atelier_PEEL.html`.** Same reason: it is the file that has
been renamed to `FR1_famille_atelier_PEEL.html`, which is what the hub links to
and what was returning 404.

## What changed

* `FR1_famille_atelier_PEEL.html` — the page behind the 404. It existed all

* `index.html` — two activities that were live but unlisted now appear under

## One consequence worth knowing

Adding two activities inside Grammar shifts the position of the four
activities after it (Vocabulary and Speaking). A progress code carries
positions, not names, so a code made *before* this upload and pasted *after*
it would read those four wrongly. The catalogue fingerprint changes with it,
so the dashboard can tell — and the problem clears itself as soon as students
send again.
